Changes
=======

Unreleased
----------
* Added `plugbench.tokenFile`, a path to a file containing the token, read
  when each pluggo starts instead of being copied into the Nix store.  Use it
  with agenix and friends.  It takes precedence over `plugbench.token`.
* Added `plugbench.fre.enable`, which runs fre-pluggo, a frecency store, and
  `plugbench.fre.client`, which installs only its command.
* Added `plugbench.sigils.enable`, which installs `sigils` from sigils-pluggo,
  with the token, and `plugbench.sigils.package`, for window managers.
* `plugbench.token` is no longer placed in `NATS_TOKEN` in the launchd agent
  plists on darwin; it is passed on the pluggo's command line instead.
